# Q&A：常见问题与技术问题

## Q1：只想截图解题，必须配置语音识别 Key 吗？

不需要。截图解题只依赖 AI 模型 Key。语音识别 Key 只影响语音转录、语音对话、面试录音和 DashScope TTS。

## Q2：语音对话为什么需要两个 Key？

因为两件事由不同服务完成：百炼 / DashScope 负责把语音转成文字，AI 模型负责根据文字回答问题。因此语音对话需要同时配置 AI 模型 Key 和百炼 Key。

## Q3：DeepSeek 可以直接识别截图吗？

通常不可以。DeepSeek Chat、DeepSeek V 系列这类纯文本模型不能直接看图。你需要开启「独立视觉模型」，让视觉模型先识别题目文字，再交给 DeepSeek 解题。

## Q4：检测 API 连接失败怎么办？

优先检查：

1. API Base URL 是否包含 `/v1`
2. API Key 是否复制完整，前后是否多了空格
3. 模型名称是否填写正确
4. 当前服务商账号余额或额度是否可用
5. 服务商是否支持 OpenAI 兼容格式

当前版本会自动去除 Base URL 首尾空格，但 Key 和模型名仍建议手动核对。

## Q5：图片解析检测返回空内容怎么办？

通常是模型不支持图片，或视觉接口配置不完整。请检查：

1. 是否使用支持图片输入的模型，例如 GPT-4o、Qwen-VL 等
2. 如果主模型不支持图片，是否开启「使用独立视觉模型」
3. 视觉 API Base URL、API Key、模型名称是否正确
4. 测试图片是否清晰，文字是否可见

## Q6：为什么 TTS 默认关闭？

为了避免程序启动或生成答案后突然自动朗读，影响面试现场。需要朗读时，可以在设置中开启，或使用 `Alt+B` 切换。

## Q7：系统音频没有声音或转录不到面试官声音怎么办？

请检查是否启用了 Windows 的“立体声混音”，并在应用设置中选择正确的系统音频设备。部分电脑没有 Stereo Mix，需要安装官方声卡驱动或使用 VB-Cable 等虚拟音频设备。

## Q8：麦克风和系统音频有什么区别？

- **麦克风**：主要录你自己的声音
- **系统音频**：主要录电脑播放的声音，例如面试官、会议软件、浏览器音频

面试录音功能会尽量同时记录面试官和你自己的声音，便于复盘。

## Q9：回答模式应该怎么选？

- 平台只要求补全函数：选 **核心代码模式**
- 平台要求自己处理输入输出：选 **ACM 模式**
- 不是编程题，或你想让 AI 按特殊风格回答：选 **自定义提示词模式**

## Q10：`Ctrl+I` 解题思路和 `Ctrl+/` 换个解法有什么区别？

- `Ctrl+I`：把当前题目或已有答案整理成适合口述的思路说明，不输出完整代码
- `Ctrl+/`：让 AI 换一种算法、数据结构或思路重新给方案

## Q11：底部快捷键提示太多怎么办？

进入「设置 → 外观设置 → 底部快捷键提示」，只勾选自己常用的快捷键。这样可以减少主界面底部占用空间。

## Q12：代码块太长看不完怎么办？

使用 `Ctrl+Shift+J` / `Ctrl+Shift+K`。它会优先滚动当前可见代码块；如果代码块已经滚到底，再滚动主内容区域。

## Q13：窗口会不会被屏幕分享软件看到？

本项目使用 Electron 的内容保护、透明置顶窗口和相关隐藏策略，适配市面上大部分会议软件。但不同会议软件和系统版本可能变化，正式使用前务必自行测试。

## Q14：窗口挡住页面操作怎么办？

按 `Alt+M` 开启鼠标穿透，窗口仍显示但不会拦截鼠标点击。再次按 `Alt+M` 可恢复鼠标交互。

## Q15：录音文件保存在哪里？

默认保存在 `文档/InterviewCoder/Records`，也可以在「设置 → 录音设置 → 录音保存目录」中修改。录音结果为 Markdown，包含时间戳、说话人标签和录音期间截图。
