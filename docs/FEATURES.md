# 功能说明

本文按主次介绍项目功能。第一次使用时，建议先掌握主功能，再按需要启用语音、录音、TTS 和显示增强。

## 主功能 1：截图解题（最核心）

适合编程面试、在线笔试、算法题、选择题、英语题等屏幕题目。

1. 打开题目页面，让题目内容显示在屏幕上
2. 按 `Alt+Enter` 截图并新开一轮解题
3. AI 会流式输出答案
4. 如果题目内容需要补充，按 `Alt+Shift+Enter` 追加截图
5. 如果对当前解法不满意，按 `Ctrl+/` 获取另一种解法

**优先级说明**：这是本项目最核心的能力。只要 AI Key 配置正确，即可使用。

## 主功能 2：回答模式切换

默认快捷键：`Ctrl+Shift+M`

- **核心代码模式**：适合 LeetCode、牛客、面试平台函数题；只输出核心函数代码。
- **ACM 模式**：适合需要完整输入输出的在线评测；输出完整可运行代码。
- **自定义提示词模式**：适合非编程题、英语题、问答题或你想自定义回答风格的场景。

状态栏会显示当前模式。未填写自定义提示词时，快捷键会跳过自定义模式。

## 主功能 3：解题思路口述

默认快捷键：`Ctrl+I`

该功能不会重新生成完整代码，而是把当前题目或已有答案整理成适合直接讲给面试官听的说明，通常包括：

- 为什么使用这个算法或数据结构
- 代码按什么步骤实现
- 关键变量的含义
- 边界情况
- 时间复杂度和空间复杂度

适合“面试官要求解释思路”或“你需要边写代码边讲”的场景。

## 主功能 4：语音对话

默认快捷键：`Ctrl+Q`

1. 确保已配置 AI 模型 Key 和百炼 Key
2. 按 `Ctrl+Q` 开始语音输入
3. 说完后再次按 `Ctrl+Q` 结束并发送
4. AI 会根据语音文本回答，并可自动朗读

适合不方便截图时直接口头问 AI，例如：面试官追问、项目经历问答、简历问题模拟等。

## 辅助功能 1：实时语音转录

默认快捷键：`Alt+T`

实时把系统音频或麦克风声音转成文字，显示在顶部转录栏。截图解题时，当前转录文本会自动附加到题目上下文中。

适合：面试官读题、口头补充条件、英文听力题、会议场景。

## 辅助功能 2：面试录音与复盘

默认快捷键：`Ctrl+1` 开始，`Ctrl+2` 停止。

录音会同时捕获系统音频和麦克风，转写为带时间戳和说话人标签的 Markdown 记录。录音期间截图也会保存到记录中。

适合：面试复盘、整理问答、将面试记录交给 AI 分析表现。

## 辅助功能 3：TTS 答案朗读

默认快捷键：`Alt+B`

TTS 默认关闭，避免自动朗读打扰。开启后，AI 最新回答会被朗读出来。

- 浏览器内置语音：免费、无需额外配置，音质取决于系统
- DashScope CosyVoice：音质更好，需要百炼 Key，可能产生费用

## 辅助功能 4：显示、滚动和隐身控制

- `Alt+H`：显示/隐藏主窗口
- `Alt+M`：鼠标穿透，避免挡住页面操作
- `Ctrl+J` / `Ctrl+K`：上下翻页
- `Ctrl+Shift+J` / `Ctrl+Shift+K`：优先滚动当前代码块或主内容区域
- `Ctrl+=` / `Ctrl+-` / `Ctrl+0`：放大 / 缩小 / 恢复 AI 回答字号
- `Ctrl+↑↓←→`：移动窗口
