# 更新日志

## v1.11.1

- **语音转录模型可配置**：在「设置 → 语音转录」中新增“转录模型”输入框；留空时使用默认 `fun-asr-realtime`。
- **API 地址自动清理**：主模型和独立视觉模型的 Base URL 会自动去除首尾空格，减少复制配置时引入空格导致的连接失败。
- **录音与转录配置补充**：优化转录相关默认值和设置项，便于后续适配不同 DashScope / 百炼实时语音模型。

## v1.11.0

- **AI 回答字号可调**：在「设置 → 外观设置」中新增 AI 回答字号滑块，范围为 `10px`～`20px`，默认 `12px`。
- **字号快捷键**：新增 `Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 恢复默认字号。
- **正文阅读体验优化**：主界面的 Markdown 回答和代码块会跟随字号设置变化，更适合远距离或小屏幕阅读。

## v1.10.1

- **设置页结构调整**：将外观相关设置移动到更靠近隐私/显示配置的位置，减少配置入口分散的问题。

## v1.10.0

- **底部快捷键提示可配置**：在「设置 → 外观设置」中可选择主界面底部显示哪些快捷键提示。
- **支持全部快捷键提示项**：包括截图、追加截图、切换模式、解题思路、换个解法、语音对话、TTS、滚动、字号、录音等。
- **减少面试时视觉干扰**：只保留自己常用的提示项，避免状态栏过长占用显示空间。

## v1.9.0

- **状态栏快捷键体验优化**：底部状态栏展示当前回答模式，并提示下一次会切换到的模式。
- **内容滚动快捷键**：新增 `Ctrl+Shift+J` / `Ctrl+Shift+K`，优先滚动当前可见代码块；代码块到底后再滚动主内容区域。
- **API 检测增强**：检测 API 连接或图片解析时，如果接口连接成功但返回空内容，会提示检查 Base URL 是否包含 `/v1`，以及模型是否可用/是否支持图片。
- **快捷键注册优化**：避免重复注册相同快捷键，减少设置同步时的异常概率。

## v1.8.1

- **语音问答提示优化**：语音对话模式下，主界面会更清楚提示当前正在聆听，以及再次按下快捷键可结束语音输入并发送。

## v1.8.0

- **回答模式快捷键**：新增 `Ctrl+Shift+M`，可在「核心代码 / ACM / 自定义提示词」之间切换。
- **核心代码模式**：输出适合面试平台函数签名的核心代码，不额外添加 `main` 或测试用例。
- **ACM 模式**：输出完整可运行代码，包含输入读取、输出打印、必要 import/头文件。
- **自定义提示词模式**：适合非编程类场景或自定义回答风格；如果未填写自定义提示词，快捷键会自动跳过该模式。
- **回答内容格式优化**：Markdown 渲染、代码块展示和模式提示同步优化。

## v1.7.1

- **TTS 默认关闭**：避免程序启动或生成答案后自动朗读打扰使用者；需要时可在设置中开启或通过快捷键切换。
- **代码输出清理**：减少多余空行和行尾空格/Tab，让复制到在线评测平台或面试平台的代码更干净。
- **ACM 可读性优化**：强调“一页内清晰可读”，不为了压缩长度把多条关键语句挤在一行。

## v1.7.0 补充

- **解题思路快捷键**：新增 `Ctrl+I`，基于当前题目和已有上下文，输出适合直接讲给面试官听的思路说明，而不是完整代码。
- **解题思路提示词可配置**：可在「设置 → AI 设置」中配置“解题思路提示词”；留空时使用默认提示词。
- **换个解法增强**：`Ctrl+/` 会要求 AI 给出不同算法、数据结构或思路的替代方案。
